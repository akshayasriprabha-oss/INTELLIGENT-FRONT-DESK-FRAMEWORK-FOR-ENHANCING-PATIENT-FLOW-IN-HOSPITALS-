# Intelligent Front Desk Framework for Enhancing Patient Flow in Hospitals

## Overview
An AI-powered hospital front desk framework designed to improve patient flow by automating patient assessment, prioritizing cases based on severity, and supporting efficient hospital operations using Artificial Intelligence and Machine Learning.

## Features
- Automated patient triage
- AI-based severity prediction
- Symptom analysis
- Appointment scheduling
- Token generation
- Department recommendation
- Firebase database integration

## Technologies Used
- Python
- Flask
- Machine Learning
- Natural Language Processing (NLP)
- Firebase

## Future Enhancements
- Integration with Electronic Health Records (EHR)
- Real-time doctor availability tracking
- Multi-language support
- Predictive analytics for hospital resource management
